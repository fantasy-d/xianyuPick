# 联调验证清单：货源渠道配置与资产渠道回显

## 目标
用于验证以下三类能力已经打通：
- 系统设置页中的“货源渠道配置”联动正确
- 决策资产库与货源明细页面能正确展示渠道信息
- 抓取运行时能读到正确的渠道/账号集合

## 一、后端本地脚本验证

### 1. 配置归一化与运行时选择器
在项目根目录执行：

```bash
/opt/anaconda3/envs/mytools/bin/python scripts/validate_source_channel_config.py
```

预期结果：
- 输出 `status: passed`
- 至少覆盖以下检查：
  - `source_channel_storage_cleanup`
  - `custom_selected_normalization`
  - `active_pool_fallback`
  - `runtime_selection`
- 该脚本不应再伴随 FastAPI / 数据库初始化日志

```bash
/opt/anaconda3/envs/mytools/bin/python -m py_compile src/web_api/main.py src/xianyu_tools/config.py scripts/run_full_pipeline.py scripts/validate_source_channel_config.py
```

预期结果：
- 无报错退出

## 二、系统设置页联调

### 1. 登录成功账号才出现在“货源渠道配置”
步骤：
1. 打开“系统参数配置”
2. 在“货源渠道号池”中准备至少 1 个登录成功账号
3. 在“商品爬取与筛选配置 -> 货源渠道配置”查看账号列表

预期：
- 只有“登录成功且加入当前激活账号”的账号会出现
- 未登录账号不应出现在抓取账号勾选区

已验证（2026-06-24）：
- 真实页面展示：
  - `1688 货源渠道(1)`
  - 已勾选账号 `tb4884575_2012`
  - 状态 `登录正常`

### 2. 切换渠道时账号列表同步变化
步骤：
1. 在“货源渠道号池”中准备 2 个不同渠道
2. 分别为两个渠道准备不同的激活账号集合
3. 切换“货源渠道配置”的渠道页签

预期：
- 当前渠道的账号列表会同步切换
- 不会混入别的渠道账号

当前状态：
- 前端切换逻辑已具备代码实现
- 当前真实浏览器样本已补到“多渠道资产结果展示”
- 若后续需要继续验证“系统设置页中的多渠道账号切换”，还需补 2 个真实已登录渠道账号样本

### 3. 手动模式空选择拦截
步骤：
1. 在“货源渠道配置”里切换到手动勾选
2. 取消掉当前渠道的所有勾选账号
3. 点击“保存并同步配置”

预期：
- 页面出现橙色警告
- 前端阻止保存
- 不会把空的手动选择静默写入配置

### 4. 自动收敛提示
步骤：
1. 先勾选一个账号并保存
2. 回到“货源渠道号池”，把该账号移出激活账号，或让它变为不可用
3. 返回“货源渠道配置”

预期：
- 页面自动清理无效选择
- 会显示：
  - 哪些渠道被自动移除
  - 哪些账号被自动收敛
- 如果随后重新修正选择，提示会自动消失

### 5. 保存后刷新保持一致
步骤：
1. 配置一组有效的渠道/账号选择
2. 点击保存
3. 手动刷新页面

预期：
- 配置回显与保存前一致
- 若后端收敛了无效项，刷新后页面展示的是收敛后的最终结果

已验证（2026-06-24）：
- `GET /api/system/configs` 当前返回：
  - `source_channel_selection_mode = custom_selected`
  - `enabled_source_channels = [{ channel_id: \"ali1688\", account_ids: [\"ali1688-account-1\"] }]`
- 与真实页面勾选状态一致

## 四、抓取入口验证

### 1. 运行时读到正确渠道集合
执行：

```bash
/opt/anaconda3/envs/mytools/bin/python scripts/validate_source_channel_config.py
```

关注检查：
- `runtime_selection`

预期：
- 运行时条目包含：
  - `channel_id`
  - `channel_label`
  - `account_id`
  - `account_label`

### 2. 新任务落库渠道快照
步骤：
1. 用有效的渠道/账号选择发起一次新抓取
2. 等任务完成后查看对应资产详情

预期：
- 详情页的每条货源可回显：
  - `source_channel_id`
  - `source_channel_label`
  - 新任务应优先带出 `source_account_label`

## 当前已知限制
- 历史任务中的 `source_account_label` 可能为空，这是旧数据缺少账号快照，不代表新链路失败。
- 当前验证脚本聚焦后端归一化与运行时选择器，不覆盖浏览器 UI 自动化。
